# Database design

UUID public identifiers and timestamps support later APIs. Reference, master, movement, operational and periodic snapshot records are separate. Financial values are decimal; effective dates preserve master history; unique reporting grains prevent duplicates; PROTECT preserves referenced history; report workflow actions are immutable. See `architecture.md` for the ER overview.

Historical report presentation uses `ReportMasterSnapshot`, captured when a report enters `ready_for_validation`. Effective-dated identities such as official appointments, committee members, traditional-title appointments, and households use close-and-replace services. Physical infrastructure replacements retain inactive predecessors; persistent businesses and projects retain their identity with audited lifecycle changes. The complete model decisions, legacy fallback, and immutability boundary are documented in `historical-master-data.md`.

Analytics definitions are versioned by `code + version`, with only one active version per code. Definitions store source, disaggregation, missing-value, verification, support-status, and unavailability metadata. Indicator values retain value, numerator, denominator, breakdown, calculation status/notes, quality rating, and contributing-report count. Conditional unique constraints enforce one value per indicator/period at village, Tikina, and province grain. Village values are created at approval and geographic aggregates reapply formulas to summed numerators/denominators. See `indicator-definitions.md`.

Approved-report corrections use `ReportAmendment` and `ReportAmendmentChange`. The amendment has a per-report sequence, requester/reviewer evidence, status, reason, and explicit supersession lineage. A change stores the server-resolved original and reviewed replacement at field grain. Optional indicator overrides preserve both original and amended value/numerator/denominator. Approved overlays are cumulative and the latest approved correction for the same field is authoritative; the original report and indicator rows remain immutable. See `report-amendments.md`.
