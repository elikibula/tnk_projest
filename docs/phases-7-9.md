# Phases 7-9 - Quality, workflow, analytics, security and operations

Phase 7 provides versioned quality rules/issues, weighted scores, declaration-gated submission and immutable role/location-scoped Tikina/provincial transitions. Phase 8 provides documented indicator definitions/calculation, scoped filtered dashboards, Chart.js/Leaflet visualisation, and audited anonymised CSV, XLSX and PDF exports. Phase 9 provides protected evidence downloads, file validation/checksums, login throttling, authentication/audit events, production hardening, CI/security scans, backup/restore scripts, management commands and deployment/privacy/mobile documentation.

The executable MVP indicators are deliberately limited to total verified population, average household size and net migration. The larger planning catalogue remains documented but is not published as calculated output until responsible data owners approve the formulas and denominators. This prevents plausible-looking but unofficial government statistics.

Final verification currently covers the Django system check, migration drift, production deployment check, the full automated test suite, at least 80% core coverage, and Ruff correctness checks. PostgreSQL container integration and an authorised iTaukei language review remain deployment-environment acceptance activities.
